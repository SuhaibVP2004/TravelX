# TravelX – Travel Website

TravelX is a multi-page travel website developed to provide visitors with a simple and engaging way to explore destinations, discover travel packages and learn more about different travel experiences.

I built this project as part of my web development learning journey, focusing on clean layouts, responsive design and interactive website features.

## About the Project

The main goal of TravelX is to create a user-friendly travel website with an attractive design and easy navigation. It includes dedicated pages for destinations, packages, travel galleries and customer inquiries.

Throughout development, I focused on structuring the website properly, maintaining a consistent design across pages and adding interactive features using JavaScript.

## Features

- **Home:** A welcoming landing page with a travel-focused hero section.
- **About:** Information about the website and its services.
- **Destinations:** A collection of travel destinations to explore.
- **Packages:** Travel packages presented in an organized layout.
- **Gallery:** A visual collection of travel experiences.
- **Location:** Additional information about selected destinations.
- **Contact:** A contact form for customer inquiries.
- **Newsletter:** A section for newsletter subscriptions.
- **Responsive Layout:** Designed to work across desktop, tablet and mobile screens.
- **Interactive Elements:** JavaScript-based form validation, animations and other website interactions.

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, layouts and responsive design
- JavaScript – Interactive functionality and form validation
- Git & GitHub – Version control and project hosting

## Getting Started

To run this project on your local machine:

**1. Clone the repository**

```bash
git clone https://github.com/SuhaibVP2004/TravelX.git
```

**2. Open the project folder**

```bash
cd TravelX
```

**3. Run the website**

Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.
